Política de Privacidade do GoldFinance

Última atualização: 22 de novembro de 2026.

O GoldFinance é um aplicativo de finanças pessoais para Android. Esta política explica quais dados o aplicativo acessa e o que é feito com eles.

Dados que o aplicativo acessa

  • Conta Google: ao entrar, o aplicativo recebe o endereço de e-mail da conta para identificar quem está em uso. O e-mail também fica guardado na cópia local do aparelho.
  • Planilha do Google Sheets: o aplicativo lê e grava na planilha que você escolher (lançamentos, categorias e subcategorias). Para isso usa a permissão https://www.googleapis.com/auth/spreadsheets. O aplicativo só usa a planilha cujo identificador você informa; ele não pede acesso geral ao Google Drive.

Onde os dados ficam

  • Na sua planilha, na sua conta Google.
  • No seu aparelho: uma cópia local (banco SQLite) com o catálogo, os lançamentos e a fila de envio, para o aplicativo funcionar sem internet. Os dados saem do aparelho somente para a sua planilha, pelo Google.

O que não fazemos

  • Não existe servidor do aplicativo: nenhum dado seu é enviado ao desenvolvedor nem a terceiros.
  • Não usamos análise de uso, publicidade nem rastreamento.
  • Não vendemos, compartilhamos nem transferimos seus dados.
  • Não há compartilhamento de dados entre pessoas: cada pessoa usa a própria conta e a própria planilha.

Uso limitado dos dados do Google

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. Os dados do Google Sheets são usados apenas para exibir e gravar os seus lançamentos dentro do aplicativo.

Como apagar ou revogar

  • Para revogar o acesso do aplicativo: myaccount.google.com/permissions, selecione GoldFinance e remova o acesso.
  • Para apagar os dados locais: desinstale o aplicativo ou limpe os dados dele nas configurações do Android.
  • Para apagar os dados financeiros: apague ou edite a planilha no Google Sheets, que é sua.
